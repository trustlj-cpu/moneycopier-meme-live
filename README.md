# 돈복사기 · X 밈코인 글로벌 현물 자동매매 데스크

모바일/데스크톱 웹앱입니다. X API v2 공개 게시글에서 선택한 티커의 새 언급을 15초마다 감시하고, 연결한 거래소의 활성 현물 거래쌍에서 새 게시글 신호가 잡히면 시장가 매수를 제출할 수 있습니다. 자동 실행은 사용자가 앱의 `자동매매 시작`을 누른 뒤에만 시작됩니다.

## 실행

```sh
npm run build
npm run desk -- --port 4175
```

웹앱: `http://127.0.0.1:4175`. 외부 호스팅에서는 `railway.json`을 사용하고 `PORT`에 바인딩합니다. 앱 서버는 `0.0.0.0`에 바인딩할 수 있습니다. 화면에서 X API v2 bearer token과 거래소 API 키를 연결하거나, `X_BEARER_TOKEN`, `<EXCHANGE>_API_KEY`, `<EXCHANGE>_API_SECRET` 환경변수를 설정합니다. 키는 서버 프로세스 메모리에만 보관하고, 재시작/연결 해제 시 지웁니다. 거래소 키 권한에서 출금은 끄세요. 앱은 출금 API를 호출하지 않습니다.

공개 URL 배포는 Railway 프로젝트에 이 폴더를 올려 배포하면 생성됩니다. 이 작업 환경에는 Railway 로그인/배포 자격 증명이나 저장소 원격 주소가 연결되지 않아 아직 공개 URL은 발급되지 않았습니다. 공개 배포 전까지 `127.0.0.1` 주소는 이 컴퓨터에서만 열립니다.

## 연결된 거래소 어댑터

CCXT 현물 어댑터: Binance, Bybit, Bitget, Kraken, Coinbase Advanced, OKX, KuCoin, BingX. 각 거래소에서 활성 현물쌍 조회, 키 인증/잔고 확인, 사용자가 확인한 시장가 주문, X 자동 신호 주문 경로를 구성했습니다. 여덟 거래소의 공개 현물 종목 목록 응답을 확인했습니다. API 계정 인증과 실제 체결은 키를 연결하지 않아 검증하지 않았습니다.

거래소 약관상 한국 제한이 명시된 Gate는 제외했습니다. Binance는 지원 국가 목록에 대한민국을 포함합니다. Bybit/Bitget 등은 제한 국가 목록에 한국을 열거하지 않지만, 이 사실만으로 한국 거주자의 거래 자격이 보장되지는 않습니다. Kraken/Coinbase/OKX/KuCoin도 계정 KYC, 상품별 지역 제한, 거래소의 실시간 접근 결정을 따릅니다. 앱은 로그인이나 지역 제한을 우회하지 않습니다.

## 자동매매 규칙 및 한계

- X 검색 쿼리와 선택한 거래쌍 티커가 모두 언급된 새 게시글을 신호로 보고, 중복 게시글 ID는 건너뜁니다.
- 주문액, 일일 최대 주문액, 기준자산 대비 손실 정지율을 설정할 수 있습니다. 기본값은 주문당 5 quote, 일일 최대 20 quote, 손실 정지 20%입니다.
- 자동 루프는 선택한 거래쌍에서만 작동합니다. 새 X 언급마다 설정된 주문액을 매수하고, 일일 한도/손실 정지/목표 배수에 닿으면 중지합니다. 목표 100,000x는 수익 보장이 아닙니다.
- 기준자산 계산은 선택 거래쌍의 quote 잔고와 base 잔고를 기준으로 합니다. 계정의 다른 코인·거래소 자산은 목표 계산에 포함되지 않습니다.
- 거래소 API의 거래 권한과 X API 검색 권한이 실제 계정에서 허용되어야 합니다. 현재 환경에는 해당 API 키가 없어 실제 계정 인증, 자동주문, 체결을 검증하지 못했습니다.
- X 검색 토큰이 없으면 신호가 오지 않으며, 거래소 키가 없으면 주문이 실행되지 않습니다. 신규 밈코인이 연결 거래소에 상장되기 전에는 중앙화 현물 API로 매수할 수 없습니다.
